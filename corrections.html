Correction ledger

Public record • Source-linked • Newest first

When an office republishes a decision file, the tracker compares it with the previous file and records what changed. This page shows every recorded difference, including the office, report date and a link to the official source, so a correction can be checked rather than taken on trust.

Reported changes

Counts are report-level. Individual rows appear under Changed rows when an application’s published outcome changed between two files. A report with no recorded difference is not listed.

Report an error

If a row is missing, wrong or attached to the wrong report, use the structured report form. It asks for the office, report date, source URL and what needs checking. Reports are stored privately; this ledger only shows differences detected in the official files.

Report a data error

How to read a diff

  • Added: rows present in the newer file but absent from the previous one.
  • Removed: rows present in the previous file but absent from the newer one.
  • Changed: the same application number was published with a different outcome.

A large added or removed count can mean a new cumulative file rather than a correction; the source link is the authoritative record. This project does not infer missing rows or rewrite an office’s history.
