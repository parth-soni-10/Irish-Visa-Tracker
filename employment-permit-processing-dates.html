Employment Permit Processing Dates - Ireland

Irish Visa Decision Tracker • Unofficial, not immigration advice

Each published employment-permit category has its own queue. This page records the application date DETE (Department of Enterprise, Tourism and Employment) has reached in every category it publishes, the lag in days and weeks, and how each queue has moved over time. Figures come from the processing dates DETE publishes.

Observation of: 7 November 2026 · Data status: OK · Source: DETE-published processing dates

Latest processing date in each category

Categories move independently, so a single average would describe nobody. Read the row for the category you applied under.

  • Critical Skills - processing applications received on 24 October 2026, 14 days behind.
  • General (New) - processing applications received on 2 October 2026, 36 days behind.
  • ICT (New) - processing applications received on 1 November 2026, 6 days behind.
  • ICT (Renewal) - processing applications received on 3 September 2026, 65 days behind.
  • Other New - processing applications received on 2 October 2026, 36 days behind.
  • Renewals - processing applications received on 3 September 2026, 65 days behind.
  • Reviews - processing applications received on 29 April 2026, 192 days behind.

Dates can move when DETE publishes an update. Check the current official date before relying on a queue.

How to read a processing date

  • Processing date - the application date DETE says it has reached in that category. Applications received after that date have not been reached yet.
  • Lag - the gap between the processing date and the date the figure was published. It describes the queue, not your case.
  • Fast and slow categories coexist - in the observation above, the fastest and slowest categories are months apart. A permit can be quick or slow depending on which queue it joined.
  • Direction matters more than one number - a lag that grows between observations means the queue is falling further behind; one that shrinks means it is catching up.

The published date covers the whole category, not your individual application.

Official sources

DETE publishes the processing dates shown here; ISD publishes visa decisions and the list of Irish visa offices.

  • ISD visa decisions and processing times - the official published dates for visa applications and appeals.
  • ISD visa offices - which office handles which countries and application types.
  • Embassy of Ireland in India - contact details for the embassy that publishes the New Delhi decision lists.

DETE publishes its own employment-permit processing dates on enterprise.gov.ie. If a figure here disagrees with the official page, the official page is correct - please report the difference.
