Bulk application check

Up to 100 numbers • Checked in this browser • Nothing uploaded • CSV export

Paste application numbers from a spreadsheet or one per line. The page loads the compact fallback index only when you press check, matches each number across the six offices, and lets you filter and export the dated results. Application numbers are never sent to a server by this page.

How this works

  • On demand. The compact fallback index is fetched only after you press check; the homepage does not load it on first paint.
  • Local. The pasted list and results stay in this browser tab. No account, upload or public result page is created.
  • Limited. Up to 100 numbers per check. For more, split the list or use the open data files.
  • Not a status service. “Not found” means the number is not in the files this page could read; it is not a refusal.
  • CSV export includes the decision date and source report date so an adviser can keep a dated record.
