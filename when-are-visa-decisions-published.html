Publication schedule

When are Irish visa decisions published?

Expected windows as of 21 November 2026 • Not guaranteed • Independent and unofficial

Each Irish visa office publishes on its own rhythm. New Delhi updates a cumulative file on weekday mornings, three embassies publish weekly PDF reports, Dublin publishes every Tuesday and Beijing publishes irregular snapshots. This page turns the latest report dates into expected windows so you know when to look again.

Expectations, not promises. A public holiday, a local closure, a broken file link or a late upload can move any date. The office's own page is always the authority. Where a window has passed without a new file, the table says “due since” and also shows the next expected window; missed windows are not rolled forward.

Why a report can still be missing

  • The office has not published yet. The expected window is a cadence estimate, not a deadline.
  • A closure intervened. Public holidays and local embassy closures interrupt the usual pattern.
  • The file link changed. The tracker reports a gap rather than inventing rows when a link cannot be found.
  • The report is a snapshot. Beijing and Dublin can re-check an unchanged list, so a new observation is not always a new decision.
