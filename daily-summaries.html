Daily Visa Decision Summaries

Irish Visa Decision Tracker • Updated from the tracker's daily scraper run • Unofficial - not immigration advice

Every business day the Embassy of Ireland in New Delhi publishes a spreadsheet of visa decisions. This page summarises the approved and refused counts for each published day, drawn from the tracker's running record of those decisions, and points at the raw file behind every figure.

Data as of: 7 November 2026 · Scraper status: OK · Decisions on record: 42,382 · Source: /data/visa_decisions.json

How to read these counts

  • Approved - applications the embassy has marked as approved in the published daily spreadsheet.
  • Refused - applications the embassy has marked as refused.
  • Published day - the date the embassy published the file, which is not necessarily the date a decision was made on a case.
  • Closures - a day with no embassy file is a closure or placeholder, not a day with zero decisions.

Counts describe what the embassy has published. They are not an approval rate for applications submitted on that day, and they say nothing about a case that has not appeared in a published file yet.

Why a daily summary is useful

The embassy's file is a single flat list with no history and no totals. Reading it tells you what was published that day; it does not tell you how decision volume has moved, which days were closures, or whether a quiet week was a slow week or a holiday. Keeping every published day in one running record is what makes those comparisons possible, and it is why this archive keeps days that the current file no longer contains.

Because the record is complete, a missing application number means one of three things: the embassy has not published a decision for it yet, the application sits with a different visa office, or the file has not been published for that day. It does not mean the application was refused.

Official sources

This page is an independent record, not the publisher. For the authoritative list, use the official pages:

  • ISD visa decisions - the official decision lists, including the Dublin visa office, which publishes on Tuesdays.
  • ISD visa offices - which office handles which countries; New Delhi covers India, Bangladesh, Nepal and Sri Lanka.
  • Embassy of Ireland in India - the embassy's own site and contact details.

Dates and totals on official pages can change without notice. If a figure here disagrees with the official page, the official page is correct - please report the difference.

Raw data

The complete decision history is available as a public JSON file: /data/visa_decisions.json, shaped as [date, application number, decision] rows. Scraper health - last run, row count and whether the last run succeeded - is at /data/visa_meta.json. The figures above are read from that health file when this page loads, so they follow the pipeline without a redeploy.

What this is not

This is an independent, unofficial project. It is not affiliated with the Embassy of Ireland, ISD, DETE or any Irish government body. It does not give immigration advice, cannot speed up an application, and cannot guarantee an outcome. For a decision on your own case, contact ISD or the Embassy of Ireland in New Delhi.
