New Delhi Ireland visa decisions by date

Irish Visa Decision Tracker • Unofficial, not immigration advice

On most weekdays the Embassy of Ireland in New Delhi publishes a spreadsheet of visa decisions. This page explains the difference between the official file date, the day the tracker first records a row, and the date attached to an individual decision. The interactive History tab lists every tracker-observed day, with the raw file behind each figure.

New Delhi only. These counts come from the Embassy of Ireland in New Delhi. For the newest official file from all six offices, see latest Irish visa decisions today.

Looking for one application? Use the interactive History tab to filter the full published record, or search an application number. For provenance, reports and checksums, see the report archive. To compare the newest file from each office, see what changed since the previous report.

How to read these counts

  • Approved - applications the embassy has marked as approved in the published daily spreadsheet.
  • Refused - applications the embassy has marked as refused.
  • Official file day - the report date printed on the office's file. It is not necessarily the date a decision was made on a case.
  • Tracker-observed day - the date the tracker first recorded a row. The newest observed day can be partial and may not yet be in the official file.
  • Decision date - the date attached to an individual application. For weekly reports it can differ from the report date.
  • Closures - a day with no embassy file is a closure or placeholder, not a day with zero decisions.

Counts reflect decisions the embassy published that day, not your personal approval chance or the approval rate for applications submitted then.

Why a daily summary is useful

The embassy publishes only the current file; older daily lists are replaced. This archive keeps every tracker-observed day, so you can compare decision volume and see closures without calling a partial observation a completed publication day.

Because the record is complete, a missing application number means one of three things: the embassy has not published a decision for it yet, the application sits with a different visa office, or the file has not been published for that day. It does not mean the application was refused.

Official sources

For the authoritative list, use the official pages:

  • ISD visa decisions - the official decision lists, including the Dublin visa office, which publishes on Tuesdays.
  • ISD visa offices - which office handles which countries; New Delhi covers India, Bangladesh, Nepal and Sri Lanka.
  • Embassy of Ireland in India - the embassy's own site and contact details.

Dates and totals on official pages can change without notice. If a figure here disagrees with the official page, the official page is correct - please report the difference.

Raw data

The complete decision history is available as a public JSON file: /data/visa_decisions.json, with the tracker-observed date, application number and decision for each row. It is updated automatically; the latest observation may be partial.
