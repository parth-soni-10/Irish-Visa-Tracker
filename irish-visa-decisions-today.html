Each count belongs to that office's own latest file. The files cover different periods, so do not add them together as a daily total.

What “today” means here

  • New Delhi publishes a cumulative file each weekday morning. Its count is the total in the file, not the number added that day.
  • Abu Dhabi, Abuja and Ankara publish weekly reports. The report date is the end of the period, not the date of an individual decision.
  • Beijing and Dublin publish snapshots. A newer check can return the same list, so a new observation is not always a new decision.
  • A missing number is not a refusal. It may be unpublished, with another office, or in a file the tracker has not seen yet.

Check an application number

The tracker searches the published files of all six offices. It records decisions only; it cannot see an application that has not been published or tell you when a passport will be returned.
