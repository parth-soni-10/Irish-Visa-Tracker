Missing or changed office

My Irish visa number is missing or changed office

Published decisions only • Not a status check • Not legal advice

A missing number in the tracker usually means the decision has not been published in a file the tracker holds, the application is with a different office, or the number was entered differently. It is not a refusal and it is not proof that no decision exists.

1. Check the number format

  • Use the 8-digit application number on your receipt or decision email, usually prefixed with IRL.
  • Do not use a VFS reference, passport number, transaction number or the number from a different application.
  • Spaces, dashes and the IRL prefix are optional in the tracker search. Leading zeros are preserved.

More help with finding the number

2. Allow for publication lag

Offices publish on different schedules. A decision can be made before its file is published, and a file can be delayed, published late or corrected. Check the office's latest report date on Data status and the publication schedule.

3. Check whether the file moved office

Some applications are transferred between visa offices. If your receipt names one office but the decision appears under another, search all six offices rather than only the one on the receipt. The ISD visa offices page explains which office handles which countries, and Find my office can narrow the likely office from the country and category.

If the office has changed, contact the office that now holds the file. The tracker cannot transfer a file or confirm where it is.

4. If the official report has the number

Open the office page and its latest official report. If the number is in the official file but not in the tracker's results, send a correction with the number, office and report date. Do not post the number publicly.

Send a correction

What not to conclude

  • Not a refusal. A missing number is not a decision outcome.
  • Not an official status check. The tracker only reads published files; it cannot see a live application.
  • Not a reason to miss a deadline. Use the official office or your decision letter for anything time-sensitive.
