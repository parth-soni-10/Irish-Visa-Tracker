About the Irish Visa Decision Tracker

Independent project by Parth Soni • Dublin, Ireland • Last updated 21 October 2026

Every business day the Embassy of Ireland in New Delhi publishes a spreadsheet of visa decisions - one flat file with no history, no search and no trends. This site keeps a running, searchable record of those decisions and tracks the processing queues that matter alongside them.

What it tracks

  • Embassy visa decisions - each published application number, its decision date and whether it was approved or refused, searchable by application number.
  • Daily summaries - accepted and refused counts for each published day, with the applications behind those counts available on demand.
  • Stamp 1G processing - the application date ISD is currently processing, how many days behind that is, and how the lag has moved over time.
  • Employment permits - the processing date reached for each permit category, with trends and projections.
  • Community timelines - waits shared by visitors, merged into the public data file each night. They are anecdotes, not a statistical sample.

Where the data comes from

The visa decision rows come from the Embassy of Ireland, New Delhi's own published spreadsheet. A scheduled Python scraper fetches the file, handles weekends and public holidays, and commits new rows to the public GitHub repository. The Stamp 1G and employment permit figures come from the published processing dates on ISD and DETE respectively. The site reads those committed JSON files, so a pipeline run appears here without a redeploy.

You can read the same files the page reads: visa decisions, scraper health, Stamp 1G observations, employment permits and community timelines.

Who runs it

This is a personal project by Parth Soni, a data analyst in Dublin. It started as a way to answer a simple question - has my application been decided yet? - without opening a different spreadsheet every morning. The code and the data pipeline are public so the record can be checked and reused.

It is built with plain HTML, CSS and JavaScript, Python scrapers running on GitHub Actions, Cloudflare Pages for hosting and a small D1 database for the forms. There is no advertising, no paid tier and no account.

What it is not

This is an unofficial tracker. It is not affiliated with, endorsed by or operated by the Embassy of Ireland, ISD, DETE or any Irish government body. It does not give immigration advice, cannot speed up an application, and cannot guarantee an outcome. For a decision on your own case, use the official channels; the tracker only reflects what has already been published.

Corrections welcome. If a row is wrong or a processing date is out of date, email soni.soni.parth@gmail.com or open an issue with the date and source. Corrections are checked against the published source before a change.
