What still needs a human

  • Request indexing is a signed-in Search Console action under URL Inspection. The API can inspect a URL; it cannot press the button.
  • Search Console sitemap processing can remain pending for days. Use the status column rather than assuming submission equals indexing.
  • Bing needs a verified site and API key. If that key is absent, the dashboard says so instead of showing an empty success.
  • Core Web Vitals need field data; the lab number here is a regression guard, not a field measurement.
